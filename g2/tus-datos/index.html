Dónde queda cada cosaAcceso a CanvasIA opcional

En tu computador.

El material descargado vive contigo. Nobu no sube esos archivos ni sus rutas para sincronizar tu cuenta.

  • Archivos que descargaste de Canvas.
  • Rutas locales y texto extraído.
  • La base de datos local, que sirve de caché.

En tu cuenta.

El servidor guarda el estado durable de tu cuenta. La copia local permite trabajar con lo que ya se guardó, y sincronizar los cambios cuando corresponde.

  • Estado de cursos y del material.
  • Fechas y correcciones de tu cuenta.
  • Preferencias y token de Canvas cifrado.

Canvas se consulta.
No se modifica.

El token permite a Nobu leer Canvas. La aplicación no publica, entrega tareas ni modifica tus cursos.

El token se guarda cifrado en el servidor. No se vuelve a mostrar después de guardarlo. Si lo revocas o vence, tendrás que crear uno nuevo y actualizarlo en Nobu.

Una copia descargada no se elimina por sincronizar. Quitar material de tu computador es una acción que tú eliges.

La IA entra
si tú quieres.

Sin IA puedes sincronizar Canvas, descargar material y ver las fechas publicadas allí. Buscar fechas dentro de documentos y anuncios requiere un asistente.

Nobu 1.6.1 usa Codex CLI o Claude Code instalado y autenticado en el mismo computador. No instala el asistente durante el primer inicio. Iniciar sesión sólo en la web de ChatGPT o Claude no prepara ese asistente local.

El análisis usa tu cuenta y la cuota de tu proveedor. El texto del material que se analiza se envía a OpenAI o Anthropic, según el asistente utilizado. Esto es distinto de la sincronización del material: los archivos descargados no se suben como parte de ella.

Para prepararlo, sigue la guía oficial de Codex CLI o Claude Code. Luego abre Ajustes → IA en Nobu y comprueba que aparezca listo.

Puedes activar la revisión automática del material nuevo o dejarla apagada y revisar manualmente. Una cita ayuda a comprobar un hallazgo; no garantiza que la lectura sea infalible.

Sin conexión.
Con lo que ya tienes.

Puedes consultar el material y los datos que ya quedaron guardados. Necesitas internet para traer novedades de Canvas, sincronizar cambios pendientes y analizar con el proveedor de IA.
